ANSI X3.159-1989 (commonly called ANSI C89)

------------------------------
#include <string.h>

// first time standardization of string header

------------------------------
Function	Purpose

strlen()	Length of string
strcpy()	Copy string
strncpy()	Copy n characters
strcat()	Concatenate strings
strncat()	Concatenate n characters

strcmp()	Compare strings
strncmp()	Compare first n characters
strchr()	Find character
strrchr()	Find last occurrence
strstr()	Find substring

strtok()	Tokenize string

memcpy()	Copy memory
memmove()	Move memory safely
memset()	Fill memory
memcmp()	Compare memory
memchr()	Find byte in memory

------------------------------------------------------------
The header and many of its functions already existed 
in Unix implementations before 1989.

ANSI C89 did not invent them, it standardized them so that
every conforming C compiler had to provide them with
the same behavior.

Think of it like this:

------------------------------
Year	Event

1972	C language invented;
		strings represented as char[] and char*

1970s	Unix implementations provided many
		string functions (not standardized)
		
1978	K&R C
		
		named after the authors of the famous 
		C programming book:
		
		Brian Kernighan
		Dennis Ritchie
		
1989	ANSI C89 standardized <string.h> and 
		its functions

1990	ISO adopted essentially the same
		standard as ISO C90

These are the functions that have been

------------------------------
C95

No significant additions to <string.h>

------------------------------
C99

Several additions were made, including:

snprintf() (in <stdio.h>, not <string.h>)
vsnprintf() (in <stdio.h>)
Some library improvements, 
but 
<string.h> itself changed very little.

------------------------------
C11

C11 introduced optional bounds-checking interfaces 
(from Annex K), including:

memcpy_s()
memmove_s()

strcpy_s()
strncpy_s()

strcat_s()
strncat_s()

strtok_s()
strerror_s()
strlen_s() (Annex K / optional)

and others.

These are optional. 
Many popular compilers (especially GCC and Clang on Linux) 
do not implement Annex K, while Microsoft Visual 
C++ implements many of these functions.

------------------------------
C23

C23 adds and standardizes some new library functionality, 
including additions related to duplicated strings such as:

strdup()
strndup()

These functions existed for many years as POSIX extensions 
before becoming part of the C standard.
