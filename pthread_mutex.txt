List of pthread_mutex_ Functions

Function Name	Description

pthread_mutex_init				
Initializes a mutex with specified attributes.

pthread_mutex_destroy			
Destroys a previously initialized mutex.

pthread_mutex_lock				
Locks the mutex; blocks if already locked.

pthread_mutex_trylock			
Attempts to lock the mutex; does not block if already locked.

pthread_mutex_timedlock			
Attempts to lock the mutex within a specified time limit.

pthread_mutex_unlock			
Unlocks the mutex.

pthread_mutexattr_init			
Initializes a mutex attribute object.

pthread_mutexattr_destroy		
Destroys a mutex attribute object.

pthread_mutexattr_settype		
Sets the mutex type (e.g., normal, recursive).

pthread_mutexattr_gettype		
Gets the current mutex type.

pthread_mutexattr_setpshared	
Sets whether the mutex is shared between processes.

pthread_mutexattr_getpshared	
Gets whether the mutex is shared between processes.
