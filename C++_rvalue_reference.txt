------------------------------------------------------------
C++11 introduced rvalue reference
T&&

&& symbol represents rvalue reference and 
forwarding reference.

it enable move semantics and resource transfer for values.

------------------------------------------------------------
Before C++11, no concept of rvalue reference and 
forward reference,
only lvalue reference & and value passing were available.

------------------------------------------------------------
forwarding reference:
When && is used with a template type parameter where the 
type is deduced, it is called a forward reference.

------------------------------------------------------------
T&& : where T is a template paramtere that is deduced 
= forward reference.

T&& : where T is a real concrete type = rvalue reference.
