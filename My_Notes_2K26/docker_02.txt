Docker Engine = "Container Manager" (NOT inside containers)

Docker Engine runs as a systemd service on your host OS

Docker Engine = Linux daemon (dockerd)
- Runs as systemd service: systemctl status docker
- Manages ALL containers on this host
- Shares host kernel with ALL containers
- 1 Engine → 1000 containers ✓ (lightweight!)

# Check YOUR engine managing 6 containers:
docker ps                    # Lists all 6 containers
docker stats                 # Shows ALL using 1 engine
systemctl status docker      # Engine status ✓

------------------------------------------------------------
Infinite Containers from 1 Image:

# Scale to infinity!
docker-compose up --scale intake_time_service=5    ← 5 identical containers
docker-compose up --scale intake_time_service=100  ← 100 identical containers

------------------------------------------------------------
Check YOUR Docker Service:

# 1. Docker Engine status:
systemctl status docker
# Expected: "Active: active (running) since Feb 16"

# 2. Docker daemon process:
ps aux | grep dockerd
# Expected: "/usr/bin/dockerd -H fd://"

# 3. Auto-starts on boot:
systemctl enable docker    # Already done!
