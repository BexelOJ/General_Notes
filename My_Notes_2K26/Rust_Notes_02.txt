Uses trait objects (&dyn Trait or Box<dyn Trait>),

Rust favors static dispatch for performance;
dynamic only when needed (heterogeneous collections).

Rust Standard Library (std) is organized into modules 
with these core components:

------------------------------
Core Modules:

PRIMITIVES & COLLECTIONS
├── primitives (i32, f64, bool, char)
├── collections (Vec, HashMap, BTreeMap)
├── string (String, &str) 
└── slice (array slices)

ERROR HANDLING
├── result (Result<T,E>)
└── option (Option<T>)

MEMORY & OWNERSHIP
├── boxed (Box<T>)
├── rc (Rc<T>) 
├── arc (Arc<T>)
└── cell (RefCell)

ITERATORS & FUNCTIONAL
├── iter (Iterator trait)
└── ops (operator overloading)

------------------------------
I/O & System:

FILE SYSTEM    NETWORK     PROCESS
├── fs         ├── net      ├── process
├── io         └── tcp      └── env
└── stdio      (UDP/TCP)

------------------------------
Concurrency:

THREADS    SYNC     CHANNELS
├── thread ├── mutex  ├── sync (mpsc)
└── panic  └── once   └── barrier


------------------------------------------------------------
Rule: Always use {:?} for collections 
(Vec, arrays, slices, etc.)

Single primitives can use {}
