All 10 concepts

Program	- Concept

pipeBasic 		- Basic pipe()

pipeParentChild - Parent → Child

pipeChildParent - Child → Parent

pipeEOF 		- EOF / closing write end

pipeBlocking 	- Blocking read()

pipeNonBlocking - O_NONBLOCK, EAGAIN

pipeBidirectional - 
Two pipes for two-way communication

pipeProducerConsumer - Producer-consumer

pipeCapacity - Pipe buffer capacity

pipeMultipleProcess - 
Multiple processes sharing a pipe

-----------------------------------------------------
These 10 give you a good first layer. 
The next IPC layer should naturally be 

pipe → FIFO → sharedMemory → messageQueue → 
semaphore → signal → socket → UnixDomainSocket, 

because those introduce actual data/coordination 
communication between processes.

-----------------------------------------------------
For the next shared-memory section, 
the important progression would be 

shm_open → mmap → sharedReadWrite → 
synchronization → producerConsumer → 
POSIX semaphore + shared memory, 

because shared memory introduces the separate 
problem of synchronizing access to shared data
