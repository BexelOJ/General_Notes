<sys/types.h> 
defines portable integer types for system programming. 
Here's each major type:

------------------------------
Core Process/File Types:

pid_t - 
Process ID (int); used in fork(), waitpid(pid_t)
​
uid_t, gid_t - 
User/group ID (unsigned int)

off_t - 
File offset/size (long or long long)

mode_t - 
File permissions (unsigned int)

ino_t - 
File inode number (unsigned long)

dev_t - 
Device number

nlink_t - 
Hard link count (unsigned short)

------------------------------
Time/Clock Types

clock_t - 
CPU clock ticks (long)

time_t - 
Calendar time (long)

suseconds_t - 
Microseconds (long)

------------------------------
Filesystem Types

blkcnt_t - 
File block count (long long)

blksize_t - 
Filesystem block size (long)

------------------------------
IPC/POSIX Types

key_t - 
IPC key (long)

id_t - 
General ID (holds pid_t, uid_t)

------------------------------
Thread Types (if _POSIX_THREADS)
text 
pthread_t          pthread_mutex_t
pthread_attr_t     pthread_cond_t
pthread_key_t      etc.

------------------------------------------------------------
Function	Purpose

fork() 
- Creates the child process

setsid() 
- Creates a new session and detaches from the controlling terminal

chdir("/") 
- Changes the current working directory

umask() 
- Controls default permissions for newly created files

close() 
- Closes file descriptors

sleep(5) 
- Pauses execution for five seconds

------------------------------------------------------------
For a pipe created using the POSIX pipe() function in C:

- pipeFd[0] is always the read end.
- pipeFd[1] is always the write end.

------------------------------------------------------------
Format specifier - Typical matching type - Purpose

%d - int - Signed integer
%u - unsigned int - Unsigned integer
%zu - size_t - Unsigned size/count
%zd - Signed counterpart of size_t (ssize_t in POSIX) - Signed size/count
%ld - long - Signed long integer

Remember for Linux system programming:
- read() and write() return ssize_t → use %zd to print the result.
- sizeof() returns size_t → use %zu to print the result.

------------------------------------------------------------
POSIX message queues use functions such as:

- mq_open() — open or create a queue
- mq_send() — send a message
- mq_receive() — receive a message
- mq_close() — close the queue descriptor
- mq_unlink() — remove the queue name

------------------------------------------------------------
Expression	Meaning

F_SETFL - Set file status flags

O_NONBLOCK - Request non-blocking I/O

flags \| O_NONBLOCK 
- Preserve the existing flags and add the non-blocking flag

------------------------------------------------------------
Argument	Meaning

MQ_NAME	Queue name: /mq_basic
O_CREAT	Create the queue if it does not exist
O_RDWR	Open the queue for sending and receiving
0666	Permission bits requested when creating the queue
NULL	Use default queue attributes

Signal	Meaning	Typical purpose

SIGINT - Interrupt 
- User presses Ctrl+C

SIGTERM - Termination request 
- Ask a process to shut down gracefully

SIGKILL - Force termination 
- Stop a process immediately

SIGCHLD - Child status changed 
- Notify a parent about a child process event

SIGUSR1 - User-defined signal 1 
- Application-defined notification

SIGSEGV - Invalid memory access 
- Commonly raised after a segmentation fault
