Rust's Clean Separation

struct Circle;           
← **DATA ONLY** ✓ (attributes/fields)

trait Drawable {         
← **METHODS ONLY** ✓ (no data)

impl Drawable for Circle 
← **BRIDGE** ✓ (joins data + methods)

------------------------------
Objects Created from struct, NOT impl

let circle = Circle;     
// ✅ Object from STRUCT (has DATA)

circle.draw();           
// ✅ Calls trait method via IMPL bridge

------------------------------
impl ≠ object factory. impl = method attachment.
