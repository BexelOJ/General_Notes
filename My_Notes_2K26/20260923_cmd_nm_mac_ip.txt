# 1. Set the cloned MAC
sudo nmcli connection modify netplan-eth0 \
    802-3-ethernet.cloned-mac-address DA:A6:32:51:9E:59

-----------------------------------------------------
# 2. Set the static IP
sudo nmcli connection modify netplan-eth0 \
    ipv4.addresses 192.168.0.130/24

-----------------------------------------------------
# 3. Set gateway
sudo nmcli connection modify netplan-eth0 \
    ipv4.gateway 192.168.0.1

-----------------------------------------------------
# 4. Make it a static IPv4 configuration
sudo nmcli connection modify netplan-eth0 \
    ipv4.method manual

-----------------------------------------------------
# 5. Enable automatic connection
sudo nmcli connection modify netplan-eth0 \
    connection.autoconnect yes

-----------------------------------------------------
# 6. Verify the profile
nmcli connection show netplan-eth0 | \
grep -E 'cloned-mac-address|ipv4.method|ipv4.addresses|ipv4.gateway|autoconnect'

-----------------------------------------------------
MAC, IP, route, DNS, and Internet connectivity 
are not the same thing.

MAC
 ↓
Ethernet link
 ↓
IP address
 ↓
Route
 ↓
Gateway
 ↓
Internet
 ↓
DNS


A working IP doesn't guarantee a working Ethernet link.

A working Ethernet link doesn't guarantee an IP.

A working IP doesn't guarantee a route.

A route doesn't guarantee Internet connectivity.

And Internet connectivity doesn't guarantee DNS.
