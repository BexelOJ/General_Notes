Common regex patterns:

Regex	- Meaning	- Example_Match

.		Any character				a, 5, @
\d		Any digit					0, 7
\w		Letter, digit, or underscore	A, b, 5, _
\s		Whitespace					Space, tab
*		Zero or more occurrences	go* matches g, go, goo
+		One or more occurrences		go+ matches go, goo
?		Zero or one occurrence - colou?r matches color and colour
^		Start of string				^Hello
$		End of string				world$
