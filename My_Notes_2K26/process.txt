------------------------------------------------------------
STAT is also worth learning

You'll see values such as:

R
S
D
T
Z

------------------------------
These represent process states:

R → Running / runnable
S → Interruptible sleep
D → Uninterruptible sleep, usually waiting on I/O
T → Stopped/traced
Z → Zombie
------------------------------------------------------------
ps aux

a → processes from other users
u → detailed user-oriented format
x → include processes without terminals

------------------------------
ps -ef

-e and -f are separate options

-e = every process
-f = full-format listing

------------------------------
UID   → User ID
PID   → Process ID
PPID  → Parent Process ID
C     → CPU utilization indicator
STIME → Start time
TTY   → Terminal
TIME  → CPU time
CMD   → Command

------------------------------
Column	Full form	Meaning

USER - User - 
	User who owns the process

PID - Process ID - 
	Unique ID assigned to the process

%CPU - Percentage of CPU - 
	Percentage of CPU being used

%MEM - Percentage of Memory - 
	Percentage of physical RAM being used

VSZ - Virtual Memory Size - 
	Total virtual memory available to the process, usually in KB

RSS - Resident Set Size - 
	Amount of the process's memory currently resident in physical RAM

TTY - Teletypewriter / Terminal - 
	Terminal associated with the process

STAT - State - 
	Current state of the process

START - Start time - 
	When the process started

TIME - CPU Time - 
	Total CPU time consumed by the process

COMMAND - Command - 
	Command/program that started the process
