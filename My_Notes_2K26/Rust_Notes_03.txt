------------------------------------------------------------
Type	Purpose	  Analogy

Cell<T>	
Compile-time mutability (simple types)
Single room with replaceable contents

RefCell<T>
Runtime borrow checking
Room with dynamic lock (panics on violation)

------------------------------------------------------------
Cell = 
fundamental building block for mutation 
behind immutable refs

------------------------------
Naming Pattern in std::cell

Cell<T>     // Atomic mutate/get
RefCell<T>  // Reference-counted borrows  
UnsafeCell<T> // Raw pointer interior mutability
OnceCell<T> // Lazy initialization
LazyCell<T> // Compile-time lazy
