5 Methods to execute perl file:

Method 1: 
Explicitly call perlperl test.pl
perl test.pl

Method 2: (shebang executable)
Make it executable with a shebang
chmod +x test.pl   # make it executable
./test.pl

Method 3: (Inline script)
Inline script with -e
perl -e 'use warnings; my $x=10; my $y="hello"; print $x+$y;'

Method 4: (Run interactively)
perl -de0

Method 5: As a Project (Build/Module Style)

------------------------------------------------------------
DB<2>  - DeBugger
Indicates you are inside the Perl debugger.

------------------------------------------------------------
perl -de0

-d → Start the Perl debugger.
-e0 → Execute the code 0
