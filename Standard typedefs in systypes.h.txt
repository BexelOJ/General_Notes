Standard typedefs in <sys/types.h>

Type name - Description

blkcnt_t - 
File block counts (signed integer)

blksize_t - 
Block sizes (signed integer)

clock_t - 
Processor time in clock ticks or CLOCKS_PER_SEC

clockid_t - 
Used for clock ID in clock/timer functions

dev_t - 
Device IDs

fsblkcnt_t - 
File‐system block counts (unsigned integer)

fsfilcnt_t - 
File‐system file counts (unsigned integer)

gid_t - 
Group ID (integer)

id_t - 
General identifier; can hold pid_t, uid_t, or gid_t

ino_t - 
File inode number (unsigned integer)

key_t - 
IPC key (for message queues, semaphores, shared memory)

mode_t - 
File mode (permissions, etc.)

nlink_t - 
Number of hard links (integer)

off_t - 
File sizes and offsets (signed integer)

pid_t - 
Process or process-group IDs (signed integer)

size_t - 
Size of objects (unsigned integer)

ssize_t - 
Count of bytes or error indication (signed integer)

suseconds_t - 
Microseconds (signed integer, up to ±1,000,000)

time_t - 
Seconds since the Epoch (signed integer or real-floating)

timer_t - 
Timer ID returned by timer_create()

useconds_t - 
Microseconds (unsigned integer, up to 1,000,000)

uid_t - 
User ID (integer)
