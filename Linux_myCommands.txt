Permission & Ownership Commands
------------------------------
Command	Full Form	Description

chmod	- Change Mode	
Changes file permissions (read/write/execute)

chown	- Change Owner	
Changes ownership of files or directories

chgrp	- Change Group	
Changes the group ownership of files/directories

umask	- User Mask (or User file creation MASK)	
Sets default permission bits when creating 
files/directories

------------------------------
ACL (Access Control List) Commands
------------------------------
Command	Full Form	Description

setfacl	- Set File Access Control List	
Adds or modifies fine-grained ACL entries for 
files/directories

getfacl	- Get File Access Control List	
Displays ACL entries for files/directories

------------------------------
User Privilege & Password Management
------------------------------
Command	Full Form	Description

sudo	- SuperUser DO	
Run commands with elevated (root) privileges

visudo	- VI Sudo (Edit sudoers safely)	
Safely edits the /etc/sudoers file using vi or nano, 
with syntax checking

sudoers	- Sudo Users (Config File)	
Configuration file (/etc/sudoers) 
for defining sudo access rules

passwd	- Password	
Used to change user passwords

gpasswd	- Group Password	
Administer a group, including adding/removing 
members or setting group passwords

------------------------------
Quick Tips:
------------------------------
Use chmod, chown, chgrp for basic permission/ownership.

Use setfacl/getfacl for more fine-grained control 
(e.g., give user1 write access to a file owned by user2).

sudo and sudoers define who can act as root, 
and visudo is used to safely edit that configuration.

umask is critical for default file permissions 
(e.g., 0022 means files are 644, dirs 755 by default).

dd 		- Data Duplicator
------------------------------
Command	Full Form	Description

dd - Data Duplicator - Low-level tool to copy and convert 
raw data from one source to another 
(e.g., disks, partitions, ISO creation)

Why is it called dd?
It mimics the IBM JCL (Job Control Language) 
command DD (Data Definition) used in mainframes.

Its syntax is different from typical Unix tools 
(uses if=, of=, bs=, etc.)

------------------------------
Example:

dd if=/dev/sda of=/backup/image.img bs=4M status=progress

'if='
(input file/device)

'of='
(output file/device)

'bs='
(block size)

'status=progress'
(shows real-time progress)

------------------------------------------------------------
Summary Table
------------------------------
| Format | Archive Tool | Compress  | Decompress |
| ------ | ------------ | --------- | ---------- |
|  .tar	 |  tar         |  tar -cf  |  tar -xf   |
|  .zip  |  zip         |  zip      |  unzip     |
|  .gz   |  gzip        |  gzip     |  gunzip    |
|  .bz2  |  bzip2       |  bzip2    |  bunzip2   |
|  .xz   |  xz          |  xz       |  unxz      |

-c = create: it tells tar to create a new archive.

-x = extract: it tells tar to extract files from an 
archive.

-f = file: it tells tar that the next argument is the name 
of the archive file to create or extract from.

time ls -l
------------------------------

real    0m0.002s
user    0m0.001s
sys     0m0.001s

------------------------------
Meaning:
------------------------------
real: Total elapsed wall-clock time (start → end)

user: Time spent in user-mode code 
(CPU processing your code)

sys: Time spent in kernel-mode (system calls, I/O, etc.)

------------------------------
Use Cases:
------------------------------
Benchmarking performance

Comparing versions of algorithms or scripts

Debugging slow-running commands

------------------------------
Example:
------------------------------
time find / -name "myfile.txt"

→ Measures how long it takes to find that file across 
the filesystem.
