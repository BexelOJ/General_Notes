1.) File and Directory Management

Command: Year: Inventor (organization): Venue
------------------------------
ls : 1971: Ken Thompson & Dennis Ritchie (Bell Labs)
Bell Telephone Laboratories (PDP-11/PDP-7), 
1st Edition Unix

ls debuted as a basic directory lister in 
Unix 1st Edition (November 3, 1971), 
written in PDP-11 assembly. 
Evolved from CTSS listf (1961), 
retained "ls" abbreviation for teletype efficiency.​

------------------------------
cd : 1971: Ken Thompson (Bell Labs)
Bell Telephone Laboratories (PDP-7/11), 
1st Edition Unix

cd (change directory) appeared as chdir in 
Unix 1st Edition (1971), one of 60+ core commands 
including ls, cat. Written in PDP-11 assembly 
by Thompson for hierarchical filesystem 
navigation—fundamental to Unix philosophy.

------------------------------
pwd : 1974: Ken Thompson (Bell Labs)
Bell Telephone Laboratories (PDP-11), 
Version 5 Unix

pwd (print working directory) first appeared in 
Unix Version 5 (1974), inheriting from Multics print_wdir. 
Prints absolute path of current directory—essential 
for shell navigation. 
Became POSIX standard in 1988
