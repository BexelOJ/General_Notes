------------------------------------------------------------
kotlinc hello.kt -include-runtime -d hello.jar
java -jar hello.jar

hello.kt = is your Kotlin file.
kotlinc = compiles it.
-include-runtime = bundles the Kotlin stdlib.
-d = destination file (your JAR or directory).
-d hello.jar = outputs a runnable jar.

java -jar hello.jar = runs it.

------------------------------------------------------------
.kt → normal Kotlin program (needs main() and usually compiled to .jar).

.kts → Kotlin script file (can run directly, like Python).

------------------------------------------------------------
To Run the Kotlin Script:

kotlinc -script 20250821_firstKotlin.kts
