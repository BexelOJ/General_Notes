Copy a single file from server to local:
(powershell)

scp username@remote_server:/path/to/remote/file C:\Users\YourName\Desktop\

scp exin@192.168.0.102:/home/exin/Workspace/MySQL/ProjectLogin/app.py D:\WorkSpace\By_Date\ServerFlask0725

scp exin@exin-desktop:/home/exin/Workspace/MySQL/ProjectLogin/app.py D:\WorkSpace\By_Date\ServerFlask0725


------------------------------------------------------------
Copy a directory recursively from server to local:
(powershell)

scp -r username@remote_server:/path/to/remote/directory C:\Users\YourName\Desktop\

scp -r exin@192.168.0.102:/home/exin/Workspace/MySQL/ProjectLogin/ D:\WorkSpace\By_Date\ServerFlask0725


------------------------------------------------------------
scp stands for Secure Copy Protocol
It is a command-line utility that uses SSH (Secure Shell) 
to securely transfer files between a local and a 
remote machine (or between two remote machines)
