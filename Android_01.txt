------------------------------------------------------------
XML - eXtensible Markup Language

XML (used in Android, legacy systems)

It is a text-based format designed to:
 - Store and transport structured data
 - Be human-readable and machine-readable
 - Allow you to define your own custom tags

Introduced: 1996 (by W3C)

Web services (SOAP)	XML-based protocol for APIs



------------------------------------------------------------
YAML stands for:

YAML Ain’t Markup Language

YAML (most human-friendly)

Like JSON or XML, it’s purely a data format, 
not a programming or scripting language

It’s a declarative, text-based data format, commonly used for:
 - Configuration files (Docker, Kubernetes, GitHub Actions)
 - Data exchange
 - App settings (like .yaml for Python, Node.js, etc.)


Features of YAML:
Feature			Details

Human-readable	More readable than XML or JSON
Supports comments	Like # this is a comment
Hierarchical (nested)	Uses indentation instead of {} or []
Used in DevOps heavily	Docker, Kubernetes, GitHub, Ansible, etc.


------------------------------------------------------------

JSON - JavaScript Object Notation.

JSON is built using key-value pairs.

JSON (used in web APIs, modern apps)
