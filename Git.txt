------------------------------------------------------------
Suppose you start with:

main:
A → B → C → D

------------------------------
Then you create a branch from B:

git checkout -b new-feature <hash-of-B>

------------------------------
and make two commits:

main:
A → B → C → D

new-feature:
A → B → E → F

------------------------------
Now:

A exists ✅
B exists ✅
C exists ✅
D exists ✅
E exists ✅
F exists ✅

Nothing was deleted.

------------------------------
Git is preserving both futures:

           C → D
          /
A → B
          \
           E → F

------------------------------
When do C and D disappear?

Only if you move the branch pointer backwards.

git reset --hard <hash-of-B>
