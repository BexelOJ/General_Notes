------------------------------------------------------------
.text	Machine code (your program)

.data	Initialized global/static variables
.bss	Uninitialized data

.rodata	Read-only constants

.symtab, .strtab	Symbol and string tables
.rel.*	Relocation info (for linking)

------------------------------


------------------------------------------------------------
T	Text (code) section, global function
t	Text (code), local (static) function

D	Data (initialized global variable)
d	Local data section (static variable)

B	BSS (uninitialized data)
b	Local BSS

U	Undefined (external) symbol (e.g. printf)
R	Read-only data (const variables)
