Commenting in SQL:

------------------------------
1. Single-line comment using --

-- This is a comment
SELECT * FROM users;

------------------------------
2. Single-line comment using # (MySQL-specific)

# This is also a comment in MySQL
SELECT * FROM orders;

------------------------------
3. Multi-line (block) comment using /* ... */

/*
  This is a multi-line comment
  Useful for longer explanations
*/
SELECT * FROM products;
