Poky is like scaffolding for building an embedded Linux system with Yocto.

Think of it this way:

Yocto Project → The entire framework / toolbox.

BitBake → The build engine (the "make" of Yocto).

OpenEmbedded-Core (OE-Core) → The essential metadata and recipes (like the foundation bricks).

Poky → A ready-made scaffolding / starter distro that puts all of the above together so you don’t start from zero.

------------------------------------------------------------
With Poky you can:

Build a minimal Linux image immediately.

Use it as a template to extend for your board (Raspberry Pi, BeagleBone, custom SoC, etc.).

Replace bits (like adding meta-raspberrypi, meta-qt5, or your own meta-myproject) on top of it.

So yes — Poky = Yocto’s reference scaffolding.
Once you’re comfortable, you can either:

keep Poky as your base, or

drop it and create your own custom distro layer.

Create a new user (example: yocto):
adduser yocto

Give it sudo rights:
usermod -aG sudo yocto

Switch to that user:
su - yocto

Fix permissions on your Yocto folders 
(since they are owned by root now):
sudo chown -R yocto:yocto ~/yocto

Enter your build directory and set up env again:
cd ~/yocto/poky/build
source ../oe-init-build-env
