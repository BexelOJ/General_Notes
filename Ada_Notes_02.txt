leading space (or - sign for negative numbers), 
to maintain alignment and fixed-width formatting

Q.) What is a subtype exactly?
A subtype defines a subset of values of an 
existing (base) type with optional constraints.

Q.) the use of subtype in ada ? just for name aliasing ?

In Ada, subtype is more than just a name alias,

it’s a way to create a new type view that can:

1.) Restrict the range or values allowed from an existing 
	type

2.) Add constraints like ranges, discrete sets, or modular 
	ranges

3.) Improve code readability and intent clarity

4.) Help the compiler catch invalid values early by 
	enforcing these constraints

subtype Age_Type is Integer range 0 .. 150;

Here, Age_Type is a subtype of Integer but restricted 
to values between 0 and 150.

-----------------------------------------------------
range 0 .. 150
is inclusive of both ends—that means it allows all values 
from 0 through 150, including 0 and 150.

-----------------------------------------------------
record is a composite data type used to group related 
values (called components or fields) under a single 
name—similar to a struct in C/C++.

type Person is record
   Name  : String(1 .. 50);
   Age   : Integer;
   Alive : Boolean;
end record;

This defines a type Person with three fields:

Name of type String

Age of type Integer

Alive of type Boolean

General Purpose of 'Image
It is used to convert strongly-typed values into String.

Examples:

Value Type			'Image Output

Integer'Image(42)	" 42"
Float'Image(3.14)	" 3.14000E+00"
Boolean'Image(True)	"TRUE"
Day'Image(Monday)	"MONDAY" (Enum)

Note: There's usually a leading space in numeric outputs 
(for sign alignment).

Typical Usage
Mostly used with:

Put_Line(Some_Type'Image(Value));

Put_Line only accepts String
'Image gives you a String representation

-- Ada has 4 main loop types:

-- 1. FOR loop (discrete range)
for J in Int_List'Range loop     -- J = 1,2,3,4,5
   Put_Line(Integer'Image(Int_List(J)));

-- 2. WHILE loop
Count : Integer := 0;
while Count < 5 loop
   Put_Line("Count: " & Integer'Image(Count));
   Count := Count + 1;

-- 3. INFINITE loop + exit
loop
   exit when Done;  -- Break equivalent
   Process_Data;
end loop;

-- 4. CONTAINER iterator (Ada 2012)
for E of My_Vector loop  -- E = each element
   Process(E);

=> (arrow operator) is used in 4 main places in Ada:

------------------------------
1. Array Aggregate (your Int_List context)

Int_List : array (1 .. 5) of Integer := 
   (1 => 10, 3 => 30, others => 0);  
   -- Index => Value
-- Result: [10, 0, 30, 0, 0]

------------------------------
2. Record Aggregate

type Person is record
   Name : String(1..10);
   Age  : Integer;
end record;

P : Person := (Name => "John     ", Age => 25);

------------------------------
3. Parameter Association (named parameters)

procedure Calc(X, Y, Z : Integer);

Calc(Z => 5, X => 10, Y => 20);  
-- Order doesn't matter!

------------------------------
4. Case Expression (Ada 2012)

Result := (case Day is
   when Monday    => 1,
   when Tuesday   => 2,
   when others    => 0);

------------------------------
Most Common: others =>

-- Initialize all elements
Arr : array(1..100) of Integer := (others => 0);

-- Fill specific + rest
Arr : array(1..5) of Integer := (2|3 => 99, others => 0);
-- Result: [0, 99, 99, 0, 0]

------------------------------
=> always means "PUT this value INTO that position"
Index/Field/Param => Value

Ada subtypes support 6 major constraint types
Range is the most common

------------------------------
1.) range_constraint:

Applies To:
Integer, Float, Enum

Syntax Example:
subtype X is Integer range 1 .. 100;

------------------------------
2.) digits_constraint:

Applies To:
Float types

Syntax Example:
subtype Metric is Float digits 8;

------------------------------
3.) delta_constraint:

Applies To:
Fixed-point

Syntax Example:
subtype Price is Delta 0.01 range 0.0 .. 999.99;

------------------------------
4.) index_constraint:

Applies To:
Arrays

Syntax Example:
subtype Vec3 is Vector(1..3);

------------------------------
5.) discriminant_constraint:

Applies To:
Records

Syntax Example:
type Rect(X, Y: Positive); 
subtype Square is Rect(Z, Z);

------------------------------
6.) predicate:

Applies To: Any type (Ada 2012+)

Syntax Example:
predicate Valid_Grade (G) is G >= 0 and G <= 100;

------------------------------
-- Range (most common)
subtype Business_Day is Day range Monday .. Friday;

-- Digits (float precision)

-- Array index
subtype Short_String is String(1 .. 10);

-- Predicate (dynamic)
subtype Even_Nums is Integer with 
   predicate Even_Nums(X) => X mod 2 = 0;
