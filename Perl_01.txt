TOML = Tom’s Obvious, Minimal Language
It’s a configuration file format 
(like JSON/YAML, but simpler)

------------------------------------------------------------
ExtUtils::MakeMaker - very old-school, lots of boilerplate.
Dist::Zilla - very powerful, but plugin-heavy and hard 
to maintain.
Minilla → lightweight, opinionated, modern replacement.

Files Minilla creates (which you saw):
Build.PL → build script (Perl equivalent of Makefile)
cpanfile → dependencies list
minil.toml → project config (name, version, license, etc.)
META.json → machine-readable metadata (for CPAN)
lib/ → where your Perl module code lives
t/ → tests (Perl convention)
Changes → changelog
README.md → documentation

------------------------------------------------------------
Workflow with Minilla:

cpanm Minilla          # install
minil new MyProject    # create a new project
cd MyProject
minil build            # build the dist
minil test             # run tests
minil release          # release to CPAN

------------------------------------------------------------
Perl one-liner example that filters,
only ERROR lines from /var/log/syslog:

perl -ne 'print if /ERROR/' /var/log/syslog

------------------------------------------------------------
Case-insensitive search (error, Error, ERROR, etc.):
perl -ne 'print if /error/i' /var/log/syslog

Show only lines with "ssh":
perl -ne 'print if /ssh/' /var/log/auth.log

Filter multiple files at once:
perl -ne 'print if /failed/i' /var/log/syslog /var/log/auth.log


------------------------------------------------------------
Minilla and ExtUtils::MakeMaker different tools in Perl, 
but they solve a similar problem — 
managing, building, and distributing Perl projects.

------------------------------------------------------------
ExtUtils::MakeMaker (EUMM)

Oldest and traditional system (exists since the 1990s).
You write a Makefile.PL (instead of Build.PL or minil.toml)

------------------------------------------------------------
Minilla

A modern CPAN module authoring tool 
(like Ruby’s Bundler or Node’s npm init).
You write only a small config file: minil.toml.
