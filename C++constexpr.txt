------------------------------------------------------------
constexpr itself was introduced in C++11, not C++20.

But C++20 greatly expanded what constexpr can do! 

------------------------------------------------------------
constexpr Timeline

Standard	What’s new with constexpr?

C++11	Introduced constexpr for functions and variables — 
		functions must be very simple 
		(single return statement, no loops, 
		no mutable state).
		
C++14	Relaxed restrictions — 
		allowed loops, multiple statements, 
		local variables inside constexpr functions.
		
C++17	More improvements, 
		e.g., constexpr lambdas.
		
C++20	Major extensions: 
		allowed constexpr for 
		dynamic memory allocation (new/delete), 
		virtual calls, try/catch, 
		and more complex code inside constexpr functions

------------------------------------------------------------
So in C++20:

You can do much more complex computations at compile time.

You can even allocate and deallocate memory inside 
constexpr functions.

Virtual functions can be constexpr.

Exception handling (try/catch) is allowed in constexpr.

------------------------------------------------------------
constexpr is a 'specifier' in c++

constexpr can be used with both variables and functions in
C++

constexpr variable:
is a constant whose value is evaluated 
and known at Compile time.

constexpr function: 
is a function that can be evaluated at 
compile time when called with constant expresions 
as arguments, 
if evaluated with non-consdtant inputs or in runtime 
context, it behgaves like a normal function, but enables 
compile-time optimization when possible.
