For Linux kernel debugging and embedded development, 
you'll use roughly 30–50 instructions most of the time.

------------------------------
Mnemonic	Full meaning	Purpose

mov	: Move
// Copy data between registers

ldr	: Load Register
// Read data from memory into a register

str	: Store Register
// Write data from a register to memory

stp	: Store Pair
// Store two registers to memory

ldp	: Load Pair
// Load two registers from memory

b	: Branch
// Unconditional jump

bl	: Branch with Link
// Call a function

ret	: Return
// Return from a function

add	: Add
// Addition

sub	: Subtract
// Subtraction

cmp	: Compare
// Compare two values

adr : Address
// 

adrp : Address of 4 KB Page
// Compute the base address of a memory page

cbz : Compare and Branch on Zero
// 

cbnz : Compare and Branch on Non Zero
// 

and : Logical AND
// Performs a bitwise AND operation

orr : Logical OR
// Performs a bitwise OR operation

eor : Exclusive OR
// Performs a bitwise XOR operation

lsl : Logical Shift Left
// Shifts bits to the left

lsr : Logical Shift Right
// Shifts bits to the Right

nop : No Operation
//

-- TUI is the GDB text based interface.

-- Tracing of program execution without stopping the program.

-- User-defined commands.

------------------------------
Type "help" followed by a class name
for a list of commands in that class.

Type "help all" 
for the list of all commands.

Type "help" followed by command name
for full documentation.

Type "apropos word" to search
for commands related to "word".

Type "apropos -v word"
for full documentation of commands related to "word".

Command name abbreviations are allowed if unambiguous.
