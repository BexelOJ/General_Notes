The grep command, 
short for "global regular expression print," scans files 
or input streams for lines matching specified patterns 
using regular expressions. 
It outputs matching lines, optionally with file names, 
line numbers, or context, but does not list directory 
contents or locate files by name.

grep operates on file contents after files are specified.

grep searches for patterns within the content of files, 
not for files themselves in a directory.

------------------------------------------------------------
For finding files in directories, use
 
find
ls
locate
