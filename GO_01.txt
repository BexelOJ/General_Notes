Go Variable Types:
 

------------------------------------------------------------
Go’s standard library keeps things simple and efficient.

Major Data Structures:

------------------------------
Array

Fixed-size, homogeneous elements.

[5]int{1,2,3,4,5}

------------------------------
Slice (most common in Go)

Dynamic view over arrays, resizable.

[]int{1,2,3}

------------------------------
Map (hash map / dictionary)

Key–value pairs.

map[string]int{"Alice": 25, "Bob": 30}

------------------------------
Struct

User-defined composite type.

Like class but no inheritance.

type Person struct {Name string; Age int}

------------------------------
Channel

For concurrency, not in all languages.

Used for communication between goroutines.

Go doesn’t have built-in sets or queues, 
but they can be built using map and slice.
